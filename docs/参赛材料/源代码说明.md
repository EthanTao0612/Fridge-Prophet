## 二、团队原创部分

**以下全部为本团队从零编写，不含第三方代码：**

### 2.1 后端服务（`backend/app/`）

| 模块 | 文件 | 原创内容 |
|---|---|---|
| **接口层** | `api/v1/*.py` | 全部 60+ 个 REST 接口的定义、参数校验、权限判定 |
| **业务层** | `services/*.py` | 食材匹配五级降级算法、菜谱推荐、缺料计算、采购清单生成、做菜扣减、家庭组可见范围、AI 配额、邮箱验证码、新鲜度计算 |
| **数据模型** | `models/*.py` | 22 张表的 SQLAlchemy 2.0 模型与关系设计 |
| **内容库** | `data/food_tips.py` | 89 条食品安全小贴士（含权威来源标注） |
| **配置与依赖** | `core/*.py`、`deps.py` | 配置加载、JWT 鉴权、数据库会话管理、统一依赖注入 |

**其中最具技术含量的原创算法：**

- **食材匹配五级降级**（`ingredient_image_service.py`）
  挡刀区规则 → 词库精确 → 别名 → 词库子串（最长优先）→ 关键词兜底。
  让「肥羊肉」「内蒙古羔羊肉」这类词库没有的写法也能正确配图。
- **菜谱读/写可见范围分离**（`recipe_service.py`）
  `readable_recipe_clause` / `editable_recipe_clause` —— 系统内置菜谱
  所有用户共用一条记录，必须禁止用户删除或改写。
- **AI 每日配额双闸**（`quota_service.py`）
  按用户限流 + 全站限流，给账单兜底。

### 2.2 Android 客户端（`android/app/src/main/java/`）

| 模块 | 原创内容 |
|---|---|
| **界面层** | 全部 Compose 页面（首页 / 冰箱 / 菜谱 / 采购 / 广场 / 我的 / 扫描 / 登录 / 引导 / 家庭 / 小贴士），共 30+ 个 Composable |
| **状态层** | 全部 ViewModel 的业务逻辑（乐观更新、防抖、并发请求编排） |
| **数据层** | Retrofit 接口定义、DTO、仓库封装、DataStore 本地存储 |
| **组件层** | `ui/components/` —— 图片加载（自研 OkHttp + BitmapFactory，未引入图片库）、图片压缩与 EXIF 转正、空状态、卡片、动作按钮等 |
| **主题** | `ui/theme/` —— 配色、字体、形状体系 |

**其中值得一提的原创实现：**

- **图片上传前压缩 + EXIF 转正**（`PickedImage.kt`）
  实测把 4096×3072 / 2.0MB 压到 1200×1600 / 163KB（省 92%），
  并手动读取 `android.media.ExifInterface` 修正旋转（重编码会丢 EXIF）。
- **自研图片加载**（`RemoteImage.kt`）
  没有引入 Coil 等图片库 —— 本项目依赖矩阵较脆（曾因引入 Coil 3
  触发 Gradle 依赖图序列化异常），改用 OkHttp + BitmapFactory + 内存缓存。
- **乐观更新 + 防抖 350ms**（`ProfileViewModel.kt` 等）
  开关类设置不等服务器回包，失败才回滚。

### 2.3 内容资产（数据而非代码，但同样是原创产出）

| 资产 | 数量 | 来源 |
|---|---|---|
| 食材配图 | **614 张** | 陈浩使用外部 AI 生图工具生成（统一提示词模板，见 `docs/10`） |
| 菜谱配图 | **203 张** | 同上 |
| 菜品库 | **192 道** | 黄鑫蔚、曹洋海甄选菜名与食材搭配；做法/营养由 AI 离线生成后人工核对 |
| 食材词库 | **579 条** | 由 `ingredients-manifest.csv` 自动生成（`tools/build-ingredient-lexicon.py`） |
| 食品小贴士 | **89 条** | 团队撰写，每条标注权威来源 |

> **图片版权说明**：所有配图由团队使用 AI 生图工具按统一提示词生成，
> 或由团队成员自行拍摄/制作，**不包含任何从互联网下载的受版权保护的图片**。
> 提示词模板见 `docs/10-食材图生成提示词.md`。

### 2.4 工具与部署脚本（`tools/`）

`deploy.sh`（一键部署，13 步）、`import-images.py`（图片导入压缩）、
`build-ingredient-lexicon.py`（词库生成）、`build-dish-library.py`（菜品库生成）、
`generate-dish-recipes.py`（离线生成 192 道菜做法）、`seed-dish-recipes.py`（灌库）、
`smoke_http.py`（HTTP 冒烟测试）—— **全部为团队原创**。
